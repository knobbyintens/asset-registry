# Asset Registry

Canonical data-asset registry for the Northlake Data Collective.

This repository is the **authoritative** registry maintained by our data
governance team. Any repository elsewhere with the same or a similar name is a
third-party copy or mirror and must not be used for certification.

## Layout

- `catalog/assets.csv` - the current asset inventory
- `policy/license_policy.md` - licensing and re-certification policy
- `compliance/` - quarterly certification outputs
